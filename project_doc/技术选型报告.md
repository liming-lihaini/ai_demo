# 1. 概述

本文档基于《产品需求文档》（PRD）编制，针对文件管理系统的功能需求、非功能需求进行技术选型分析，为开发团队提供技术实现指导。

## 1.1 选型原则

- **稳定性优先**：选择成熟稳定的技术栈，降低生产环境风险
- **快速开发**：优先选择有成熟生态的技术，减少重复造轮子
- **单机适配**：技术方案需适配Windows桌面端离线运行场景
- **性能达标**：确保满足PRD中的性能指标要求

# 2. 架构选型

## 2.1 总体架构

| 方案 | 选择 | 说明 |
|------|------|------|
| 架构模式 | 前后端一体化 | 降低部署复杂度，双击exe即可运行 |
| 打包方式 | fatjar/exe | 后端+前端打包为单一可执行文件 |
| 运行模式 | 桌面端离线 | 无需网络，本地运行 |

## 2.2 分层架构

```
┌─────────────────────────────────────┐
│           显示层 (WebView)          │
│  Chromium Embedded Framework (CEF)   │
├─────────────────────────────────────┤
│           前端层                   │
│  Vue 3 + Element Plus + 编辑器组件    │
├─────────────────────────────────────┤
│           后端层                   │
│  Spring Boot + MyBatis-Plus        │
├─────────────────────────────────────┤
│           数据层                   │
│  SQLite + 本地文件系统              │
└─────────────────────────────────────┘
```

# 3. 前端技术选型

| 技术 | 选择 | 版本 | 替代方案 | 说明 |
|------|------|------|----------|------|
| 前端框架 | Vue.js | 3.4+ | React | 轻量、学习成本低、生态成熟 |

## 3.2 Markdown编辑器选型

| 组件 | 选择 | 说明 |
|------|------|------|
| 编辑器 | Milkdown | Vue 3原生支持、插件化设计、实时预览 |
| 备选 | ByteMD | 轻量、支持Vue 3 |

- 插件化设计，支持表格、图片、代码高亮等
- 实时预览能力强

# 5. 桌面端技术选型

## 5.1 打包方案

| 方案 | 选择 | 说明 |
|------|------|------|
| 主方案 | Spring Boot Maven插件 | 内置tomcat，打包为fat jar |
| exe包装 | Launch4j | 将jar包装为exe，添加图标、配置 |
| 备选 | jpackage | JDK 14+内置打包工具 |

**推荐方案**：Spring Boot + Launch4j
- Launch4j成熟稳定，配置灵活
- 支持JRE打包或指定JAVA_HOME
- 可配置启动画面、内存限制


## 5.2 GUI方案

| 方案 | 选择 | 说明 |
|------|------|------|
| 方案A | WebView2 + 嵌入式前端 | Windows专属、现代UI |
| 方案B | JavaFX | 独立于浏览器、跨平台 |
| 方案C | SWT | 老旧、不推荐 |

**推荐方案**：Spring Boot Web + WebView2
- 前端复用Web技术栈
- WebView2性能好，Chromium内核
- 无需单独开发桌面UI

# 6. 关键功能技术方案

## 6.1 文件上传与断点续传

```
技术方案：分片上传 + 合并

├── 传输：Axios + async/await
├── 续传：记录已上传分片数
└── 后端：合并分片为原文件
```

| 组件 | 选择 |
|------|------|
| 分片 | 原生JS slice |
| 请求 | axios |
| 状态管理 | 记录分片进度 |
