# 1. 项目概述

基于《技术选型报告》构建的文件管理系统，采用前后端一体化架构，Spring Boot + Vue 3 + SQLite技术栈。

# 3. 四层架构约束

## 3.1 分层规则

```
Controller → Service → Repository → Model
```

| 层级 | 职责 | 禁止操作 |
|------|------|----------|
| Controller | 参数校验 + 响应格式化 | 业务逻辑 |
| Service | 业务逻辑核心，事务边界 | 直接访问数据库 |
| Repository | 数据访问，封装SQL | 业务逻辑 |
| Model | 数据模型定义 | 业务方法 |

## 3.2 目录命名规范

| 包/目录 | 命名 | 说明 |
|---------|------|------|
| 后端包 | com.filemanager | 根包名 |
| Controller | *Controller.java | 后缀Controller |
| Service | *Service.java | 后��Service |
| Repository | *Repository.java | 后缀Repository |
| Model | *DO/*.java/*.xml | 数据对象/XML映射 |
| 前端视图 | *.vue | 单文件组件 |
| 前端API | *.js | API封装 |

# 4. 数据库设计规范

## 4.1 表命名

| 表名 | 说明 | 命名规则 |
|------|------|----------|
| 用户表 | users | 复数小写，下划线分隔 |
| 目录表 | directories | 同上 |
| 文件表 | files | 同上 |
| 日志表 | operation_logs | 同上 |

## 4.2 字段命名

| 类型 | 命名 | 示例 |
|------|------|------|
| 主键 | id | id |
| 外键 | entity_id | user_id |
| 名称 | name | name |
| 时间 | *_at | created_at |
| 软删除 | deleted | deleted (0/1) |

## 4.3 索引

- 主键：id（自增）
- 外键：user_id
- 唯一索引：username、md5+parent_id
- 普通索引：parent_id、deleted

# 5. API规范

## 5.1 RESTful风格

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/directories | 目录列表 |
| POST | /api/directories | 创建目录 |
| PUT | /api/directories/{id} | 更新目录 |
| DELETE | /api/directories/{id} | 删除目录 |
| GET | /api/files | 文件列表 |
| POST | /api/files/upload | 文件上传 |
| DELETE | /api/files/{id} | 删除文件 |

## 5.2 响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

# 8. 配置规范

## 8.1 应用配置

```yaml
# application.yml
server:
  port: 8080

spring:
  datasource:
    url: jdbc:sqlite:db/fileManager.db
  servlet:
    multipart:
      max-file-size: 100MB
      max-request-size: 100MB

storage:
  path: ./storage/files
  temp-path: ./storage/temp
  cache-path: ./storage/cache

app:
  upload:
    max-size: 100MB
    max-batch: 50
    allowed-extensions: doc,docx,xls,xlsx,ppt,pptx,pdf,txt,md,jpg,jpeg,png,gif,bmp,mp3,wav,mp4,avi
  trash:
    keep-days: 30
```

# 10. 安全约束

## 10.1 禁止规则

| 规则 | 说�� |
|------|------|
| SQL拼接 | 禁止SQL字符串拼接，使用参数化查询 |
| 明文密码 | 禁止明文存储密码 |
| 文件上传 | 禁止上传可执行文件（.exe/.bat/.jar） |
| 路径遍历 | 防止../路径穿越攻击 |

## 10.2 敏感操作

- 删除文件：二次确认
- 文件替换：确认提示
- 批量操作：确认提示
