# Plan 阶段知识

## 阶段目标

将设计决策转化为可执行计划，明确 Task 列表、依赖关系、验收条件。

## 关注重点

1. **Task 拆分**: 每个 Task 涉及 1-2 个文件，可独立验证
2. **依赖关系**: 明确 Task 之间的依赖，避免循环依赖
3. **验收条件**: 每个 Task 有明确的验收标准

## Task 结构

| 字段 | 说明 |
|------|------|
| Task ID | 唯一标识，如 Task 1, Task 2 |
| 内容 | 具体要实现的内容 |
| 依赖 | 依赖的其他 Task |
| 验收条件 | 如何验证完成 |

## 验收标准原则

- 明确：可客观判定
- 可测：可验证通过/失败
- 具体：涉及哪个文件、哪行代码

## 输出

- docs/plans/{date}-{issue-title}-实现计划.md
- pipeline-state-{issue编号}.md 的 Current Stage 更新
