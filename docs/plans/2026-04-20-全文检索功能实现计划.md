# 全文检索功能实现计划

Issue: #6 | 日期: 2026/04/20 | 状态: 待实现

## 概述

实现文件和目录的全文检索功能，使用 SQLite FTS5 全文搜索引擎。

## 技术决策

- 索引更新: 定时更新（每5分钟批量同步）
- 搜索历史: 前端 localStorage
- FTS5 表: 分离设计（file_fts, directory_fts）
- API: 多接口分离

4. 类型筛选 → 按文件类型筛选结果
5. 日期筛选 → 按创建/修改时间筛选
6. 大小筛选 → 按文件大小区间筛选
