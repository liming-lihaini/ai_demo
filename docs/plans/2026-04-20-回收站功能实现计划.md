## Task 5: 创建 TrashService 回收站业务逻辑
做什么: 新建 TrashService.java，实现回收站核心业务逻辑（列表查询、恢复、永久删除、定时清理）
涉及文件:
  - file-manager/src/main/java/com/filemanager/service/TrashService.java (新建)
验收条件:
  - 提供 getTrashList(userId) 方法，返回已删除的文件和目录列表
  - 提供 restoreFile(id) 方法，恢复文件（设置 deleted=0, deleteAt=null）
  - 提供 restoreDirectory(id) 方法，恢复目录（设置 deleted=0, deleteAt=null）
  - 提供 permanentDeleteFile(id) 方法，物理删除文件
  - 提供 permanentDeleteDirectory(id) 方法，物理删除目录
  - 提供 cleanExpiredItems() 方法，删除超过30天的项目
依赖: Task 3, Task 4

## Task 6: 创建 TrashController 回收站 API 接口
做什么: 新建 TrashController.java，实现回收站 API 接口
涉及文件:
  - file-manager/src/main/java/com/filemanager/controller/TrashController.java (新建)
验收条件:
  - GET /api/trash/list?userId=1 - 返回回收站列表
  - POST /api/trash/file/{id}/restore - 恢复文件
  - POST /api/trash/directory/{id}/restore - 恢复目录
  - DELETE /api/trash/file/{id} - 永久删除文件
  - DELETE /api/trash/directory/{id} - 永久删除目录
  - DELETE /api/trash/clear?userId=1 - 清空回收站
  - 响应格式符合 {code, message, data} 规范
依赖: Task 5
