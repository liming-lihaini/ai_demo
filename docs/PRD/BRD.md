# 文件管理系统技术需求规格书

# 1. 引言

## 1.1 文档目的

本文档旨在明确文件管理系统的技术需求，包括功能需求、非功能需求、接口需求、数据需求等，为系统设计、开发、测试及部署提供标准化依据，确保系统满足用户对文件目录、文件操作、文件预览及在线Markdown编写的核心需求，同时保证系统的稳定性、安全性和易用性。

## 1.2 适用范围

本文档适用于文件管理系统的开发团队（前端、后端、测试）、产品团队、运维团队及相关 stakeholders，作为系统开发、测试验证、部署实施的核心参考文档。

## 1.3 术语与定义

- 文件目录：用于分类组织文件的逻辑结构，支持层级嵌套，类比操作系统的文件夹结构。

- Markdown（MD）：一种轻量级标记语言，可通过简单标记符号实现文本的格式化展示，支持标题、列表、链接、图片等格式。

- 在线MD编写：用户在系统中直接创建、编辑MD文件，实时预览编辑效果，无需本地编辑器。

- 文件预览：系统支持对常见格式文件（文档、图片、音频、视频、MD等）进行在线查看，无需下载至本地。

- 文件元数据：描述文件属性的信息，包括文件名、大小、创建时间、修改时间、文件类型、存储路径等。

# 2. 系统概述

本文件管理系统是一款桌面单机运行的软件，支持文件目录层级管理、文件全生命周期操作、多格式文件在线预览及在线Markdown编写，可通过exe文件直接启动运行，无需复杂部署，无需依赖网络（离线可用），旨在为个人用户提供便捷、高效、安全的本地文件管理解决方案。系统采用前后端不分离架构，将前端交互与后端业务逻辑集成于一体，降低部署复杂度；数据库采用本机免安装的开源数据库，无需用户手动安装配置，启动exe后自动初始化数据库，确保单机运行的便捷性和稳定性。

# 3. 功能需求

## 3.1 文件目录管理

### 3.1.1 目录创建

- 用户可在指定父目录下创建新目录，需输入目录名称（必填，长度1-50字符，不允许包含特殊字符【/ \ : * ? " < > |】）。

- 创建目录时需校验目录名称唯一性（同一父目录下不允许存在同名目录），校验失败需提示用户“当前目录下已存在同名目录，请修改名称后重试”。

- 目录创建成功后，系统自动记录目录的创建人、创建时间、父目录ID等元数据，并同步更新目录层级结构。

### 3.1.2 目录编辑

- 用户可修改自有目录的名称，修改规则与创建时一致（名称长度、特殊字符限制、唯一性校验）。

- 支持目录移动操作，可将目录移动至其他存在的父目录下，移动后目录的层级结构同步更新，目录下的所有子目录和文件随之移动。

- 编辑操作需记录操作日志（操作人、操作时间、操作类型、修改前内容、修改后内容），支持后续追溯。

### 3.1.3 目录删除

- 用户可删除自有目录，删除前需弹窗确认，提示“删除此目录将同时删除其下所有子目录和文件，是否确认删除？”。

- 支持批量删除目录，批量删除时同样需进行确认提示，且仅能删除用户有权限操作的目录。

- 删除操作支持回收站机制，删除的目录及下属内容暂存至回收站，保留30天，期间可恢复；超过30天自动永久删除，不可恢复。

### 3.1.4 目录查询与导航

- 支持目录层级导航，用户可通过面包屑导航快速定位当前目录位置，并跳转至上级目录。

- 支持目录搜索，可根据目录名称模糊查询，搜索结果实时展示，点击搜索结果可直接跳转至对应目录。

- 展示当前目录下的子目录列表，显示目录名称、创建时间、创建人等基础信息，支持按名称、创建时间升序/降序排序。

## 3.2 文件管理

### 3.2.1 文件上传

- 支持单个/多个文件上传，单个文件大小限制≤100MB，支持批量上传的文件数量≤50个/次。

- 上传文件时可选择目标目录，默认上传至当前所在目录；支持拖拽文件至指定目录完成上传。

- 上传过程中显示上传进度（百分比），支持暂停、继续上传，上传失败时提示失败原因（如文件过大、格式不支持、网络异常等），并支持重新上传。

- 文件上传成功后，系统自动记录文件元数据（文件名、大小、格式、创建人、上传时间、存储路径、MD5值），MD5值用于校验文件唯一性（同一目录下不允许上传MD5值相同的文件，避免重复上传）。

- 支持常见文件格式上传，包括但不限于：文档类（doc、docx、xls、xlsx、ppt、pptx、pdf、txt、md）、图片类（jpg、jpeg、png、gif、bmp）、音频类（mp3、wav）、视频类（mp4、avi）。

### 3.2.2 文件编辑

- 支持修改文件名称，修改规则与目录名称一致（长度1-50字符，不允许包含特殊字符，同一目录下文件名唯一）。

- 支持文件移动操作，可将文件移动至其他存在的目录下，移动后文件的存储路径同步更新，元数据中的父目录ID随之修改。

- 支持文件替换操作，用户可上传新文件替换原有文件（保持文件名不变，更新文件内容、大小、MD5值、修改时间），替换前需确认提示。

- 编辑操作需记录操作日志，包括操作人、操作时间、操作类型、文件信息（修改前/后），支持追溯。

### 3.2.3 文件删除

- 用户可删除自有文件，删除前需弹窗确认，提示“是否确认删除此文件？删除后将进入回收站，30天后自动永久删除”。

- 支持批量删除文件，批量删除时需确认提示，仅能删除用户有权限操作的文件。

- 删除的文件暂存至回收站，保留30天，期间可单个/批量恢复至原目录；超过30天自动永久删除，不可恢复；回收站支持手动清空操作（清空后文件不可恢复）。

### 3.2.4 文件查询与筛选

- 支持文件搜索，可根据文件名模糊查询，搜索结果实时展示，点击结果可直接预览或编辑文件。

- 支持按文件类型、大小、上传时间、创建人进行筛选，筛选条件可组合使用（如筛选“图片类”且“上传时间近7天”的文件）。

- 文件列表展示文件名称、大小、格式、上传时间、创建人等信息，支持按名称、大小、上传时间升序/降序排序。

### 3.2.5 文件下载

- 支持单个文件下载，点击文件下载按钮，自动触发下载，保存至本地指定路径。

- 支持批量文件下载，选择多个文件后，系统自动将其压缩为ZIP包，再触发下载，压缩包名称格式为“文件批量下载_当前时间戳”。

- 下载过程中显示下载进度，下载失败时提示失败原因，并支持重新下载。

## 3.3 文件预览

### 3.3.1 预览支持范围

- 文档类：支持pdf、txt、md文件直接在线预览；支持doc、docx、xls、xlsx、ppt、pptx文件转换为可预览格式（如PDF）后在线查看，转换时间≤5秒（单个文件≤20MB）。

- 图片类：支持jpg、jpeg、png、gif、bmp文件在线预览，支持放大、缩小、旋转、切换图片（同一目录下多个图片）操作。

- 音频类：支持mp3、wav文件在线播放，提供播放、暂停、音量调节、进度拖拽功能。

- 视频类：支持mp4、avi文件在线播放，提供播放、暂停、音量调节、进度拖拽、全屏播放功能，支持自适应播放窗口大小。

### 3.3.2 预览操作体验

- 点击文件名称或预览按钮，弹出预览窗口（全屏/弹窗模式），预览窗口支持关闭操作。

- 预览过程中，支持切换至编辑模式（如MD文件可直接进入在线编辑）、下载文件、删除文件操作。

- 对于较大文件（如≥20MB的文档、视频），预览时显示加载进度，加载完成后再展示内容，避免卡顿。

## 3.4 在线MD编写

### 3.4.1 MD文件创建

- 用户可在指定目录下创建MD文件，需输入文件名（必填，后缀为.md，长度1-50字符，不允许包含特殊字符，同一目录下唯一）。

- 创建成功后，自动进入在线编辑界面，默认显示空白编辑区域和预览区域（分屏模式）。

### 3.4.2 MD编辑功能

- 编辑模式：支持分屏编辑（左侧编辑区、右侧实时预览区）和单屏编辑（仅编辑区/仅预览区，可切换）。

- 基础格式化：支持标题（H1-H6）、加粗、斜体、下划线、删除线、引用、代码块（行内代码、块级代码，支持语法高亮）、有序列表、无序列表、分割线等基础MD格式。

- 高级功能：支持插入链接（自定义链接文本、链接地址，支持跳转预览）、插入图片（可上传本地图片或输入图片URL，支持图片大小调整）、插入表格（自定义行数、列数，支持编辑表格内容、合并/拆分单元格）。

- 编辑辅助：支持自动保存（每30秒自动保存一次，避免编辑内容丢失）、手动保存、撤销（Ctrl+Z）、重做（Ctrl+Y）操作。

- 语法提示：编辑过程中，对错误的MD语法进行提示（如未闭合的引用、表格格式错误），提示方式为红色下划线，鼠标悬浮显示错误原因。

### 3.4.3 MD文件保存与导出

- 手动保存：点击保存按钮，系统更新文件内容、修改时间、MD5值，保存成功后提示“保存成功”。

- 自动保存：编辑过程中每30秒自动保存一次，保存成功后在页面角落显示“已自动保存”提示，无需用户手动操作。

- 导出功能：支持将MD文件导出为纯MD文件（.md）、PDF文件（.pdf）、HTML文件（.html），导出时保持原有的格式化样式。

### 3.4.4 MD文件预览与分享

- 编辑过程中，右侧预览区实时展示编辑效果，与最终导出/预览效果一致。

- 支持MD文件单独预览（脱离编辑模式），预览时展示完整的格式化内容，支持放大、缩小、复制文本操作。

- 支持生成MD文件预览链接（临时链接，有效期可设置为12小时、24小时、7天），用户可将链接分享给他人，他人通过链接可查看MD文件预览内容（不可编辑）。

# 4. 非功能需求

## 4.1 性能需求

- 响应速度：页面加载时间≤2秒，目录/文件列表加载时间≤1秒，文件上传/下载速度根据网络环境自适应，单个10MB文件上传时间≤10秒。

- 并发能力：单机模式下支持单用户多任务并发操作（如同时进行文件上传、MD编辑、文件预览），无卡顿、无崩溃，确保单用户操作体验流畅。

- 处理能力：单个目录下支持最大文件/目录数量≤1000个，系统可正常加载、操作；文件转换（如doc转pdf）单个文件≤20MB时，转换时间≤5秒。

## 4.2 安全性需求

- 用户权限：单机模式下仅支持单用户操作，无需多用户角色管理，用户对所有本地目录、文件拥有全部操作权限，确保操作便捷性，同时通过本地文件加密、数据库加密，防止本地数据被非法访问、篡改。

- 文件安全：上传的文件需进行病毒扫描（支持常见病毒、恶意文件检测），检测到危险文件时禁止上传，并提示用户；文件存储采用加密存储，防止文件被非法访问、篡改。

- 操作安全：敏感操作（如删除、替换、批量操作）需进行二次确认；操作日志完整记录所有用户的操作，包括操作时间、操作类型、操作内容，日志存储在本地数据库，保留90天，支持查询、导出。

- 数据安全：定期对文件数据、用户数据进行备份（每日增量备份，每周全量备份），备份数据保留30天，支持数据恢复（如系统故障、数据丢失时可恢复至指定备份点）。

## 4.3 易用性需求

- 界面设计：界面简洁、直观，操作流程清晰，符合用户使用习惯；导航明确，用户可快速找到所需功能（目录管理、文件上传、MD编辑等）。

- 操作提示：所有操作（成功、失败、确认）均有明确提示，错误提示需清晰、易懂，指导用户解决问题（如文件上传失败提示“文件大小超过限制，最大支持100MB”）。

- 兼容性：支持主流浏览器（Chrome、Firefox、Edge、Safari），版本要求为最新版本及前两个版本；支持PC端使用，适配不同屏幕分辨率（1366×768及以上）。

## 4.4 可扩展性需求

- 架构可扩展：采用前后端不分离架构，代码集成度高、部署便捷，预留功能扩展接口，便于后续新增文件格式支持、本地存储扩展等功能，适配单机使用场景的升级需求。

- 功能可扩展：系统预留接口，支持后续新增文件格式支持、第三方存储集成（如阿里云OSS、腾讯云COS）、多用户协作等功能。

- 存储可扩展：支持存储容量动态扩展，当存储容量不足时，可通过增加存储节点或扩容存储设备实现容量提升，不影响系统正常运行。

## 4.5 可靠性需求

- 系统稳定性：系统连续运行时间≥7×24小时，无异常崩溃、死机现象；平均故障间隔时间（MTBF）≥1000小时，故障修复时间（MTTR）≤1小时。

- 容错性：用户操作失误（如输入非法字符、上传不支持格式文件）时，系统不崩溃，给出明确提示并引导用户纠正；离线状态下，所有操作正常执行，数据实时存储在本地数据库，无数据丢失风险。

# 6. 数据需求

## 6.1 数据分类

- 用户数据：单机模式下仅支持单用户，数据包括用户名、密码（加密存储）、创建时间、最后登录时间，存储在本地开源数据库中，无需多用户管理。

- 目录数据：包括目录ID、目录名称、父目录ID、创建人ID、创建时间、修改时间、是否删除（逻辑删除标识）。

- 文件数据：包括文件ID、文件名、文件格式、文件大小、MD5值、存储路径、父目录ID、创建人ID、上传时间、修改时间、是否删除（逻辑删除标识）。

- 操作日志数据：包括日志ID、操作类型（创建、编辑、删除、上传、下载等）、操作内容、操作时间，存储在本地数据库，无需记录IP地址（单机离线使用）。

- MD文件数据：除文件数据外，额外存储MD文件的编辑内容（明文存储，便于编辑和预览）、最后编辑时间。

## 6.2 数据存储

- 关系型数据（用户、目录、文件元数据、操作日志）：采用本机免安装的开源数据库（SQLite 3.40.0及以上），无需用户手动安装、配置，启动exe文件后系统自动初始化数据库，自动创建所需数据表，确保数据本地存储、安全可控，同时支持数据库文件本地备份。

- 文件内容存储：采用本机本地存储模式，所有用户文件、系统程序文件均存储在用户指定的本地磁盘路径（默认路径可修改），支持外接移动存储扩展，无需分布式存储，适配单机离线使用场景，确保文件访问速度和安全性。



# 7. 运行环境需求

## 7.1 单机运行环境

- 操作系统：Windows 10及以上（32位/64位）、Windows 11（32位/64位），暂不支持Linux、MacOS系统。

- CPU：≥2核，主频≥2.0GHz。

- 内存：≥4GB（推荐8GB），确保exe启动后系统运行流畅，无卡顿。

- 存储：本地磁盘可用空间≥50GB，用于存储系统程序、用户文件、本地数据库文件及数据备份，支持外接移动存储扩展。

- 运行要求：无需安装额外依赖组件、无需手动安装数据库，双击exe文件即可启动系统，启动时间≤10秒；启动后自动初始化本地开源数据库、配置系统参数，无需用户手动设置。

- 兼容性：exe程序支持桌面快捷方式创建，支持最小化至系统托盘，关闭exe程序后系统停止运行，数据库自动断开连接，再次启动可恢复上次操作状态及所有本地数据。


## 7.2 开发环境

- 前端：Node.js（≥16.0）、Vue.js（≥3.0）、Element Plus（UI组件库）、Markdown编辑器组件（如mavon-editor），与后端集成开发，不单独部署。

- 后端：Java（≥JDK 11）、Spring Boot（≥2.7）、Spring Security（权限控制）、MyBatis-Plus（数据访问），与前端集成，打包为exe可执行程序。

- 数据库：SQLite（≥3.40.0），本机免安装开源数据库，无需单独部署，集成于exe程序中，启动后自动初始化。

- 工具：Maven（构建工具）、Git（版本控制）、Postman（接口测试，仅用于开发阶段内部测试）、exe打包工具（如Launch4j）。

## 7.3 测试环境

测试环境配置与单机运行环境一致，重点针对exe启动、本地数据库初始化、离线操作、数据备份与恢复等核心场景进行功能测试、性能测试、安全性测试，确保单机模式下系统无重大bug，重点测试exe启动速度、本地数据库稳定性、离线文件操作流畅度及数据安全性。

测试环境配置与生产环境（Web模式）、单机运行环境分别对应一致，分别针对Web模式和单机exe模式进行系统功能测试、性能测试、安全性测试，确保两种运行模式下系统上线前无重大bug，其中单机模式重点测试exe启动速度、离线运行稳定性及本地文件操作流畅度。

# 8. 验收标准

## 8.1 功能验收

- 文件目录管理：所有目录操作（创建、编辑、删除、查询、导航）均能正常执行，符合3.1节需求，无异常。
