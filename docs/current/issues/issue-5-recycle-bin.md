# ISSUE-回收站功能

## 概述

实现回收站功能，包括查看、恢复、清空、自动清理已删除的文件和目录。

## 功能需求

### F-TRASH-001 回收站管理

| 需求项 | 内容 |
|--------|------|
| 需求名称 | 回收站管理 |
| 需求描述 | 管理回收站中的文件和目录 |
| 显示 | 展示回收站中的目录和文件列表 |
| 恢复 | 支持单个/批量恢复至原目录 |
| 自动清理 | 30天后自动永久删除 |
| 手动清空 | 支持一键清空（清空后不可恢复） |

## 技术方案

### 数据结构变更

**文件表 (files)** 和 **目录表 (directories)** 需添加删除时间字段：

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| deleted | TINYINT | DEFAULT 0 | 逻辑删除（已有） |
| delete_at | DATETIME | - | 删除时间（需新增） |

### 接口设计

| 接口 | 方法 | 路径 | 功能 |
|------|------|------|------|
| 回收站列表 | GET | /api/trash/list | 获取已删除文件+目录列表 |
| 恢复文件 | POST | /api/trash/restore/{id} | 恢复文件/目录到原位置 |
| 永久删除 | DELETE | /api/trash/{id} | 物理删除（不经过回收站） |
| 清空回收站 | DELETE | /api/trash/clear | 清空全部已删除项 |

### 业务规则

1. 保留30天后自动永久删除
2. 恢复时检查原目录是否存在，如不存在提示用户
3. 清空操作需二次确认
4. 恢复后 `deleted=0`，`delete_at=null`
5. 物理删除后同时删除存储文件

### 定时任务

- 每日凌晨执行，查询 `delete_at` 超过30天的记录
- 物理删除数据库记录和存储文件

## 验收条件

1. **查看回收站** → 显示已删除的文件/目录列表，显示原位置和剩余天数
2. **恢复单个** → 文件/目录回到原目录，deleted=0
3. **手动清空** → 确认后清空全部，物理删除
4. **自动清理** → 30天后自动删除过期项

## 依赖

- 目录管理模块（DirectoryService）
- 文件管理模块（FileService）
- 前端回收站页面（Trash.vue）
